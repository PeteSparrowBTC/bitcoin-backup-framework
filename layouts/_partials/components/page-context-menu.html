{{/* Page context menu, overriding the theme's. WHAT CHANGES, AND WHY The theme's version is a copy-as-markdown button with a dropdown, and the assistant links are an optional extra hanging off the bottom. Here the assistants are the whole point and the markdown handling is gone: - "Copy as Markdown" and "View as Markdown" are removed. They are also not configurable in the theme, which is the only reason this file exists. - The primary button is now the FIRST entry in page.contextMenu.links, so which assistant is the default is decided in hugo.yaml rather than here. No vendor name appears in this template. - The dropdown holds the remaining entries, and is not rendered at all when there is only one, because the theme's JS reads the dropdown out of the container on finding a toggle and would meet a null. A SIDE EFFECT WORTH KEEPING The theme's copy button pre-fetches each page's markdown on DOMContentLoaded, so every page was making an extra request on load, and on the front page that request was a 404. Dropping the button drops the fetch. THE SECOND CONTROL "Suggest a change" sits beside the assistants rather than inside their dropdown, because it is a different kind of act: one is asking a machine about the page, the other is telling a person the page is wrong. Burying the second in a menu opened for the first would mean nobody finds it, and this document has changed several times because a reader pushed back on a specific claim. It opens a GitHub issue form with the page already filled in, which is the cheapest route that still produces something actionable: no fork, no branch, no knowledge of which source file a page came from. WHAT STAYS The markdown output formats stay configured. Nothing here needs them now, but /framework/index.md and friends remain fetchable, which is what /llms.txt points an assistant at, and the guard in scripts/check-no-external-requests.sh still passes because every link below is an the reader chooses to follow rather than something the browser loads on its own. Classes are copied from the theme so this renders as native rather than as an override. Keep them in step if the theme's styling moves. */}} {{- $enableGlobal := site.Params.page.contextMenu.enable | default false -}} {{- $enablePage := .Params.contextMenu -}} {{- $enable := cond (ne $enablePage nil) $enablePage $enableGlobal -}} {{- $links := site.Params.page.contextMenu.links | default slice -}} {{- if and $enable $links -}} {{- $pageURL := .Permalink -}} {{- $pageTitle := .Title -}} {{- $markdownURL := "" -}} {{- with .OutputFormats.Get "markdown" -}}{{- $markdownURL = .Permalink -}}{{- end -}} {{- $values := dict "url" $pageURL "title" $pageTitle "markdown_url" $markdownURL -}} {{- $primary := index $links 0 -}} {{- $rest := after 1 $links -}} {{- $primaryURL := partial "utils/template-url.html" (dict "template" $primary.url "values" $values) -}}
